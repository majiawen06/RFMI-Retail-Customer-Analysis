# 基于RFM-I改进模型的线上零售用户分层与转化卡点研究
> 本项目在传统RFM模型基础上新增意向相关指标，识别转化卡点、高意向潜客与假性流失用户，输出运营投放优化方案
技术栈：MySQL、Excel、PowerBI

## 📌 项目概述
1. 研究背景
2. 传统RFM模型存在的缺陷
3. 研究目的：构建RFM-I改进模型、识别转化卡点、优化用户分层
4. 技术栈：MySQL、Excel、PowerBI

## 📊 数据说明
1. 数据集来源：Kaggle线上零售五表仿真数据集
2. 五张表结构介绍、表关联关系
3. 所需字段说明

## 🗄️ 数据预处理（MySQL）
> 本模块用于展示SQL能力
1. MySQL多表关联查询（用户表+订单表+行为会话表联表）
2. 数据清洗：去重、空值处理、异常值过滤
3. 指标计算（MySQL完成全部核心计算）
    - R/F/M 基础指标
    - I意向分、转化摩擦系数、活跃连接度
    - 购买力分层修正
4. NTILE窗口函数打分
5. CASE WHEN 完成RFM-I用户分层标签

## 📋 数据校验与二次处理（Excel）
> 本模块用于展示Excel能力
1. 导出MySQL结果明细至Excel
2. 数据透视表核验指标合理性
3. 异常样本复核、分层结果校验
4. 整理规范最终分析数据集

## 🔍 模型构建与分析核心（项目亮点）
1. RFM-I改进模型构建逻辑
2. 四大新增指标业务解释
3. 传统RFM VS RFM-I分层结果对比分析
4. 高意向高摩擦潜客人群分析
5. 假性流失用户特征分析
6. 不同购买力层级用户行为差异分析

## 📈 可视化看板搭建（PowerBI）
> 本模块用于展示PowerBI能力
1. 星型模型搭建、维度表/事实表建立关系
2. DAX度量值编写（核心指标）
3. 交互式看板三大模块
    - 整体数据大盘
    - RFM&RFMI分层对比看板
    - 用户摩擦卡点分析看板
4. 切片器、筛选、钻取功能应用
